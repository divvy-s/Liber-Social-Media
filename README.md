# Liber

Liber is a decentralized social media platform inspired by Reddit.  
It is built around the principles of transparency, ownership, and community-driven governance.

## Features

- **NFT-based identities**: Every profile and post is represented as an NFT, ensuring ownership and verifiability.
- **Decentralized discussions**: Posts and comments are stored on-chain, with attributes linking comments to their parent posts.
- **Community-driven interactions**: Upvotes and downvotes replace traditional likes and shares, emphasizing quality over virality.
- **Web3 integration**: Powered by smart contracts for trustless functionality.

## Tech Stack

- **Smart Contracts**: Solidity  
- **Frontend**: React + Tailwind CSS  
- **Backend**: Node.js, MongoDB  
- **Blockchain**: Ethereum-compatible chain
